# Dave the Viber

A night sushi bar in pixel art for [T3 Code](https://github.com/pingdotgg/t3code). Threads hang as kitchen
order slips on a rail, finished threads are spiked on a spindle, and the project header is a noren with a
restaurant sign. It looks the same in OS light and dark mode.

Install: import `out2/full.json` in T3 Code (Settings → Appearance). `out2/lite.json` is a smaller edition.

Local edition (T3 Code with theme background images): copy both files of `out2/local/` into your T3 Code themes
folder (`~/.t3/userdata/themes/`), then pick Dave the Viber in Settings → Appearance. It looks the same as the
full edition; its sprites come from the image file instead of the CSS.

Inspired by the sushi-bar mood of *Dave the Diver*. Not affiliated with or endorsed by MINTROCKET or NEXON.
All art is original.
